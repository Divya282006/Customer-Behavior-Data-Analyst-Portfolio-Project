# Customer Behavior Data Analysis

An end-to-end data analytics project focused on analyzing customer shopping behavior and identifying meaningful patterns in purchasing, customer segments, product preferences, discounts, and loyalty.

## 📌 Project Overview

This project analyzes a retail customer shopping dataset to understand how different customer characteristics and purchasing factors influence shopping behavior.

The project covers the complete analytics workflow, including:

* Data loading and preparation using Python
* Data cleaning and transformation using Pandas
* Exploratory Data Analysis (EDA)
* SQL-based business analysis
* Customer segmentation and purchase pattern analysis
* Data visualization using Power BI
* Generation of actionable business insights

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **SQL**
* **PostgreSQL**
* **Power BI**
* **Jupyter Notebook**

## 📂 Dataset

The dataset contains **3,900 customer records** with information related to:

* Customer demographics
* Items purchased
* Product categories
* Purchase amounts
* Locations
* Seasons
* Ratings
* Subscription status
* Shipping methods
* Discounts and promotional codes
* Previous purchases
* Payment methods
* Purchase frequency

## 🔍 Data Preparation & Cleaning

The dataset was prepared and cleaned using Python and Pandas. The process included:

* Loading the CSV dataset into a Pandas DataFrame
* Inspecting the dataset structure and data types
* Identifying missing values
* Handling missing review ratings using category-wise median imputation
* Standardizing column names
* Creating an **Age Group** feature
* Converting purchase frequency into a numerical representation
* Checking the relationship between discount and promotional-code fields
* Removing redundant columns where appropriate
